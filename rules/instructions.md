## Optional rules

Optional rules apply only when their descriptions match the current task or the user explicitly requests them.

Use the summaries below to select which optional rules to read. Read only matching rules and follow their full instructions; these summaries do not replace their detailed applicability or authorization requirements.

- **build-documentation.md:** Read when the user requests `Create Build Documentation`, or when a materially significant build may warrant recommending a documentation record. `{project-path}\rules\optional\build-documentation.md`
- **command.md:** Read when the user defines a deferred command, asks the agent to wait for a named phrase, or requests discussion or analysis without changes yet. `{project-path}\rules\optional\command.md`
- **project-conventions.md:** Read when designing, implementing, reviewing, or documenting project work. `{project-path}\rules\optional\project-conventions.md`
- **project-creation.md:** Read when creating a solution or component project, or adding a supported component project to an existing solution. `{project-path}\rules\optional\project-creation.md`
- **project-layout.md:** Read when creating a new project or when the user explicitly requests restructuring an existing project. `{project-path}\rules\optional\project-layout.md`
- **project-structure.md:** Read when creating, changing, or reviewing a project's internal file and directory structure. `{project-path}\rules\optional\project-structure.md`
- **required-project-files.md:** Read when creating a new project or adding standard base files to an existing project. `{project-path}\rules\optional\required-project-files.md`
- **visualize-ui.md:** Read when the user requests a UI visualization or preview for critique or approval, or when a rendered preview would resolve a material design decision before implementation. `{project-path}\rules\optional\visualize-ui.md`
