# Implementation scope

**rule-name:** implementation-scope
**absolute-path:** `{project-path}\base\project-conventions\instructions\general\implementation-scope.md`
**absolute-directory:** `{project-path}\base\project-conventions\instructions\general`
**rule-description:**

Always read the referenced implementation-scope convention before changing a project's implementation or determining whether a proposed change is authorized.

The convention permits relevant inspection across component projects and defines which projects may be modified by default, which modifications require explicit user authorization, and the exceptions for project creation and project-wide validation.
