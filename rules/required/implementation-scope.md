# Implementation scope

**rule-name:** implementation-scope
**absolute-path:** `{project-path}\base\project-conventions\instructions\general\implementation-scope.md`
**absolute-directory:** `{project-path}\base\project-conventions\instructions\general`
**rule-description:**

Always read the referenced implementation-scope convention before inspecting or changing a project's implementation.

The convention defines which component projects are available by default, which require explicit user authorization, and the exceptions for project creation and project-wide validation.
