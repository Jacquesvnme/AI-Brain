# Git commits

**rule-name:** git-commits
**rule-description:**

AI assistants must not stage changes or create Git commits during ordinary work.

The only permitted exception is the one-time initial baseline commit created as part of establishing a brand-new base project under the required-project-files instructions. That exception applies only after the entire initial project baseline is complete and verified, and only when the new project does not already belong to a Git repository or have Git history.

Do not infer permission to stage or commit from requests to implement, change, fix, finish, verify, or otherwise complete work. After the initial base-project exception has been used, leave all later changes uncommitted.
