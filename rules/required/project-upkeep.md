# Project upkeep

**rule-name:** project-upkeep
**absolute-path:** `{project-path}\projects\project-upkeep.md`
**absolute-directory:** `{project-path}\projects`
**rule-description:**

Apply this required rule when the current repository or product has a matching directory under `projects`.

Read the referenced upkeep instructions and update only documents whose factual content materially changed. Do not update `other-notes.md` without an explicit user request.
