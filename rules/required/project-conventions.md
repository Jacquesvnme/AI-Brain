**rule-description:**

Always read the central project-conventions instructions before designing, implementing, reviewing, or documenting project work.

The central file is a routing document. Apply its universal conventions, then read only the detailed convention files whose descriptions match the current work. Front-end, API, domain, documentation, and related skill guidance do not apply when those concerns are outside the task.
