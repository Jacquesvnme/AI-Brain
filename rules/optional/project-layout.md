# Project layout

**rule-name:** project-layout
**absolute-path:** `{project-path}\base\project-layout\instructions.md`
**absolute-directory:** `{project-path}\base\project-layout\instructions`
**rule-description:**

Apply this optional rule only when creating a new project or when the user explicitly requests that an existing project be restructured.

The central file routes to the available solution layouts. Do not combine layouts unless the user requests a custom structure.
