# Visualize UI

**rule-name:** visualize-ui
**absolute-path:** `{project-path}\skills\custom\visualize-ui.md`
**absolute-directory:** `{project-path}\skills\custom`
**rule-description:**

Apply this optional rule when the user asks to visualize, mock up, preview, show, or compare a front-end page, section, flow, application shell, dialog, or component for visual critique or approval.

Also apply when a rendered preview would resolve a material front-end design decision before implementation.

Follow the referenced workflow and return an actual visual artifact, not a text wireframe or prose substitute. Visualization does not authorize implementation unless the user requests both.
