# Visualize UI

**rule-name:** visualize-ui
**absolute-path:** `{project-path}\skills\custom\visualize-ui.md`
**absolute-directory:** `{project-path}\skills\custom`
**rule-description:**

Apply this optional rule when the user asks to visualize, mock up, preview, show, or compare a front-end page, section, flow, application shell, dialog, or component for visual critique or approval.

Also apply it during front-end design when the implementation direction is materially visual and an inspectable preview would resolve layout, theme, hierarchy, or interaction choices before code is changed.

The deliverable must be a rendered visual such as interactive HTML, an in-conversation interactive design, PNG, SVG, or another visually inspectable format. ASCII layouts, text wireframes, Markdown tables, Mermaid diagrams, and prose-only descriptions do not satisfy this rule.

Read and follow the referenced custom instruction before creating the visual. A visualization request does not authorize implementation changes unless the user asks for both visualization and implementation.
