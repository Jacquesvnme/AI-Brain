# Base required files of the project structure

## packages.md

This is a file that will be used to list the packages used in a specific project.
This file will also list any possible powershell command used to create this project.
There can be any amount of projects.

Projects in this case refer for me to the inidividual sln files.
This is usual the case of 5 such files.

- PROJECT_NAME.Api
- PROJECT_NAME.Desktop
- PROJECT_NAME.UI
- PROJECT_NAME.Domain
- PROJECT_NAME.Test

Each project will have some sort of project file inside of its separated structures.
This project file will usually be a .csproj, or esproj file.
