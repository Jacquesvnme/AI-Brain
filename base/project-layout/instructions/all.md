# All-project layout

## Standard solution layout

Use this file to define a custom solution layout when none of the specialized layouts apply.

Keep the solution-level configuration, documentation, and shared project files in the outer project directory. Place source projects in an inner directory that uses the same project name.

```text
PROJECT_NAME/
├── .codegraph/
├── PROJECT_NAME/
├── AGENTS.md
├── Creation.md
├── LICENSE
└── README.md
```
