# React application experience conventions

These instructions add the standard React setup's entry-document and asset locations to `{project-path}\base\project-conventions\instructions\ui\generic\application-experience.md`.

## Entry document

Apply the shared document-metadata requirements in the UI project's root `index.html`. Replace the default Vite title and any framework placeholder branding with the actual application identity.

## Identity and icon assets

Create a custom `public/favicon.svg` and reference it from `index.html`. Store reusable interface and application-identity SVG artwork under `src/assets/icons`.

These locations describe the AI Brain's standard React setup. When established project tooling requires a different entry document or asset mechanism, follow that setup while retaining the shared application-experience and icon requirements.
