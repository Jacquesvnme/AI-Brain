# AI Brain

AI Brain is a central knowledge base for the rules, conventions, and reusable project resources that guide AI-assisted work across multiple software projects. Its main index, `ai-brain.md`, tells an AI agent which required rules must always be followed and which optional rules should be applied for a particular task.

The repository also contains standard project layouts, shared configuration files, documentation templates, and project-specific context. Keeping this information in one place makes project creation and maintenance more consistent while allowing common guidance to be updated without duplicating it in every repository.
