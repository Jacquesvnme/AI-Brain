# Project context

**section-name:** projects
**absolute-path:** `{project-path}\projects\instructions.md`
**absolute-directory:** `{project-path}\projects`
**section-description:**

Apply project context when the current repository or product has a matching directory under `projects`.

Read the detailed instructions first, then open only the files in the matching project directory that relate to the current task. Do not load context for unrelated projects.
