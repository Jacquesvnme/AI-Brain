# AI Brain

This is my personal AI Brain.

A centralized, opinionated reference for the choices, decisions, conventions, and development workflows I want AI assistants to follow. It is focused primarily on C# and .NET development, including project creation, solution layouts, internal project structures, architecture, handlers, controllers, domain types, validation, error handling, and documentation.

The repository also records my front-end design preferences, required and optional AI rules, reusable skills, custom workflows such as UI visualization, and project-specific reference material. These instructions are personal defaults rather than universal development standards.

Start with [`ai-brain.md`](ai-brain.md), which routes agents to the relevant rules, base guidance, skills, and project context.
